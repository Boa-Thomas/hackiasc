Metodologia · Conceito

SLC-IA — Simples, Adorável, Completo com IA real

Evolução do conceito de MVP · Jason Cohen, 2014

S

Simples

Escopo limitado; apenas o necessário para testar a hipótese mais arriscada.

L

Adorável (Lovable)

A parte que existe deve encantar; UX cuidada, tom claro, output útil.

C

Completo

Funciona ponta a ponta dentro do escopo; não está quebrado.

IA

IA real

Chamada à API, output gerado dinamicamente, custo medido — não mockado.
